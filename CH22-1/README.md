# 실습 과제 1

## 구조체가 필요한 이유를 설명하라.
- 개별적으로 사용하면 한 가지의 데이터로 묶어서 다루기 힘들기 때문에 필요하다.
- 즉, 구조체는 서로 다른 기본 자료형을 여러 개 모아서 사용자가 새롭게 정의한 자료형이다.

## 배열과 공통점과 차이점을 설명하라.
- 공통점: 관련된 데이터를 하나로 묶어서 취급 할 수 있다. 연속된 메모리 공간에 할당된다. 중괄호로 초기화한다.
- 차이점: 배열은 같은 자료형만 가능하지만 구조체는 다른 종류도 포함 할 수 있다.

## 기본 자료형과 구조체의 차이를 설명하라.
- 차이점: 하나의 변수에 저장할 수 있는 데이터의 종류이다.
   
## 구조체 정의와 구조체 변수 선언의 의미를 각각 설명하라
- 구조체 정의: 새로운 자료형을 정의하는 일
- 구조체 변수 선언: struct <구조체명> <변수명>;
