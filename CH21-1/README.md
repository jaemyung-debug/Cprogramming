# 실습 과제 1
## 스트림과 버퍼의 역할을 각각 설명하시오.
- 스트림: 프로그램과 입출력 장치 사이에서 데이터가 이동하는 통로이다.
- 버퍼: 입출력 데이터를 일시적으로 저장하는 메모리 공간이다.

## 버퍼를 사용하여 얻는 장점과 단점을 모두 설명하시오.
- 장점: 데이터를 모아서 한꺼번에 입출력하므로 입출력 횟수를 줄이고 효율을 높일 수 있다.
- 단점: 데이터가 버퍼에 남아 있으면 실제 입출력이 지연될 수 있으며, 입력 버퍼에 남은 데이터 때문에 예상하지 못한 입력이 발생할 수 있다.
  
## 입력 버퍼에 데이터가 이미 존재할 때 scanf 함수를 호출한다면 어떤 일이 발생하는가?
입력 버퍼에 데이터가 남아 있다면 scanf는 키보드에서 새로 입력받기 전에 버퍼에 남아 있는 데이터부터 읽는다. 서식 지정자에 따라 데이터를 변환하여 변수에 저장하며, 읽지 않은 데이터는 버퍼에 남는다.

## scanf함수와 printf함수 실행 시 함수와 운영체제의 역할 분담에 대하여 설명하라
- scanf 함수: 입력 스트림에서 데이터를 읽고, 지정된 형식에 따라 변환하여 변수에 저장한다. 운영체제는 키보드 등의 입력 장치에서 데이터를 전달하는 역할을 한다.
- printf 함수: 지정된 형식에 맞게 데이터를 문자열로 변환하여 출력 스트림에 기록한다. 운영체제는 출력 장치로 데이터가 전달되도록 지원한다. 출력 버퍼를 사용하는 경우 버퍼의 데이터가 실제로 출력되는 시점은 버퍼링 방식 등에 따라 달라진다.
