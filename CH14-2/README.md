# 실습 과제 1
- 주소에 의한 호출을 사용해야하는 3가지 경우를 설명하라
>함수에서 다른 함수의 지역변수를 수정하고자 할 때, 배열을 전달할 때, 함수의 리턴 값이 2개 이상인 경우 -> 첫번째 경우와 같음

- 최대값 구하는 알고리즘을 설명하라
1. 배열의 첫 번째 원소를 최대값으로 설정한다.
2. 두 번째 원소부터 최대값과 비교한다.
3. 현재 원소가 최대값보다 크면 최대값을 현재 원소로 변경한다.
4. 배열의 마지막 원소까지 2~3번 과정을 반복한다.
5. 최종적으로 저장된 값이 최대값이다.

- const 선언을 사용하는 이유를 설명 하시오.
>값의 불필요한 변경을 방지하고 프로그램을 보다 안전하고 이해하기 쉽게 작성할 수 있다.
