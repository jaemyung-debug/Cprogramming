# 실습 과제 1
## 함수 선언, 호출, 정의를 설명하라 
- 함수 선언: 함수의 이름, 반환 자료형, 매개변수의 자료형 등을 컴파일러애 알려주는 것이다. 또한 시작 주소를 알려주는 "상수"이다. 
- 함수 호출: 정의된 함수를 실행시킨다.
- 함수 정의: 함수가 실제로 어떤 작업을 하는 지에 대해 작성하는 내용이다.

## 함수의 자료형은? 
- 함수의 자료형은 반환명과 매개변수의 자료형으로 정의된다.

- 예시) 반환명(매개변수의 자료형 1,2…)

## 함수명의자료형은?
- (함수의 자료형)* → (반환명 (매개변수자료형 1, 2…))*

- 예시) 반환명(*)(매개변수자료형 1,2..) 괄호 별임 괄호 필수

## void 포인터의 용도는?
- 모든 종류의 주소를 저장 할 수 있는 변수
- 포인터는 항상 가르키는 변수의 자료형이 정해져 있다 때문에 포인터가 늘어나고 양이 많아졌을 때 가르키는 자료형마다 포인터가 팔요해지고 포인터의 양이 늘어난다 이를 줄이기 위해 VOID 즉 빈 공간의 포인터를 사용하는 것이다. 

## void 포인터에 간접 참조 연산을 적용할 때 주의할 점은?
- 연산을 적용할 때에는 VOID포인터가 강제 형 변환을 실행시키기 때믄에 가르키는 변수의 자료형을 반드시 선언해주고 사용하여야 오류 또는 원하는 리턴값을 얻을 수 있다.

## 강제 형 변환과 자동 형 변환을 설명하시오.
- 강제 형 변환: 프로그래머가 직접 자료형을 지정하여 변환하는 것이다.
- 예)
double a = 3.7;
int b;
b = (int)a;

- 자동 형 변환: 컴파일러가 자동으로 자료형을 변환하는 것이다.
- 예)
int a = 10;
double b;
b = a;
