# 실습 과제 1
## 구조체가 왜 필요한지 설명하시오.
- 구조체 즉, struct은 서로 다른 자료형의 변수들을 한 가지로 묶어 사용하여 코드의 가독성이 높아지고, 데이터를 효율적으로 관리할 수 있다.

## 공용체가 왜 필요한지 설명하시오.
- 공용체 즉, union은 서로 다른 자료형의 변수를 하나의 메모리에 할당하여 사용 할 수 있도록 하여 메모리를 효율적으로 사용하기 위해 필요하다.
  
## 열거형이 왜 필요한지 설명하시오.
- 열거형 즉, enum은 사용하면 코드의 가독성이 높아지고, 프로그램을 이해하고 수정하기 쉬워진다.
