# 실습 과제 1 
-배열명의 의미를 설명하라.
>배열 첫 번째 요소의 주소

-배열표현과 포인터(주소) 표현의 변환 공식을 설명하라.
> | 배열 | 포인터(주소) |
  |---|---|
  | a  | &a[0] |
  | a[l]  | *(a+l)  |
  | &a[l] | a+l  |

-배열의 첫번째 요소의 주소만 알면 모든 원소의 주소를 계산할 수 
있다. 방법을 설명하시오.
>배열은 연속으로 할당되는 특성이 있다. 따라서 요소의 주소를 알면 요소의 바이트 수 만큼 첫 번째에 더하여 두 번째 주소를 알 수 있고 이를 반복하면 배열의 모든 주소를 알 수 있다.

-배열의 첫번째 요소의 주소만 알면 모든 원소의 값를 계산할 수 있
다. 방법을 설명하시오.
>위 질문과 마찬가지로 모든 배열의 주소를 찾을 수 있게 되므로 원하는 배열에 값도 포인터를 활용하여 알 수 있게 된다.

-포인터에 대해 가능한 연산의 종류와 의미를 설명하라.
> 간접참조(*), 정수덧셈(+), 정수뺄셈(-), 증감(++, --)이다

-포인터 연산을 기존의 산술연산과 다르게 정의한 이유는 무엇일까
>가장 대표적인 예시로 변수 a에 1을 더하면 a+1의 값이 산출되겠지만 포인터에서는 값에 1을 더하는 것이 아니라 다음 번지의 값을 불러오게 되므로 다르게 정의한다

## a++, ++a의 차이
-a++는 값에다가 증가한 후 사용하고 ++a 증가한 후 값을 사용한다. 즉 배열에서 사용했을 때 첫 번째 칸의 값을 찾으려고 했으나 ++a를 사용하면 다음 칸의 값을 알게 된다.
