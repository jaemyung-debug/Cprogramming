# 실습 과제 1

## 표준 입출력 스트림을 접근하는 방법을 설명하라.
- 헤더 파일에 정의된 표준 스트림을 이용하여 접근한다.
- stdin: 표준 입력 스트림
- stdout: 표준 출력 스트림
- stderr: 표준 오류 스트림

## 공백을 포함한 문자열을 입력 받을 때 사용가능한 함수는?
- fgets 함수 {(n-1)개의 문자를 읽을 때까지 줄바꿈 문자를 만날 때까지 스트림의 끝을 만날 때까지 문자열을 읽어 저장하기 때문에)
  
## gets 함수사용시 가장 큰 문제점은 무엇인가?
- 입력되는 문자열의 길이가 배열 길이보다 클 경우 할당 받지 않은 메모리를 참조하는 오류가 발생한다
  
## fgets 함수 사용시 문제점은 무엇인가?
- stdin으로부터 문자열을 입력 받아서 s에 저장을 하되, 널 문자를 포함하여 지정된 크기만큼만 저장한다.
   
## 널문자(‘\0’)와 널포인터(NULL)의 용도를 설명하시오.
- 널 문자: 문자의 끝을 나타내는 문자
- 널 포인터: 유효한 메모리 주소나 객체를 가리키지 않는 포인터이다.
